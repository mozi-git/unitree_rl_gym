# GR1T1 URDF 物理特性与运动学分析报告

本报告基于 `resources/robots/gr1t1/urdf/gr1t1_12dof.urdf` 文件进行分析，旨在为 RL 训练提供准确的物理参考。

## 1. 机器人概况
*   **机器人名称**: `gr1t2` (URDF 内部定义)
*   **总质量**: 约 **53.71 kg**
*   **自由度 (DOF)**: 12 (每条腿 6 个自由度)
*   **关节配置**:
    *   髋部 (Hip): Roll -> Yaw -> Pitch
    *   膝部 (Knee): Pitch
    *   踝部 (Ankle): Pitch -> Roll

## 2. 运动学链与长度分析 (Z方向偏移)

从 `base_link` (躯干中心) 到地面的累计偏移量计算：

| 关节/连接段 | Z轴偏移 (m) | 累计 Z 偏移 (m) |
| :--- | :--- | :--- |
| `base_link` -> `hip_roll` | -0.0276 | -0.0276 |
| `hip_roll` -> `hip_yaw` | 0.0000 | -0.0276 |
| `hip_yaw` -> `hip_pitch` | -0.1405 | -0.1681 |
| `hip_pitch` -> `knee_pitch` | -0.3600 | -0.5281 |
| `knee_pitch` -> `ankle_pitch` | -0.3400 | -0.8681 |
| `ankle_pitch` -> `ankle_roll` | 0.0000 | -0.8681 |
| `ankle_roll` -> `foot_collision` | -0.0350 | **-0.9031** |

*   **全腿拉直总长**: **0.9031 米**
*   **结论**: 
    *   当 `pos[2] = 0.85` 时，机器人处于 **0.05m (5cm)** 的微蹲状态，这是一个非常健康的初始化位置。
    *   如果目标高度设为 `0.80`，则腿部压缩量约为 10cm，符合人形机器人的常规行走姿态。

## 4. 碰撞模型与传感器
*   **足部碰撞体**: 使用了两个圆柱体 (`l_foot_1`, `l_foot_2`) 模拟足底，半径 0.02m，长度 0.24m。这种配置能提供稳定的平面支撑。
*   **IMU 位置**: 安装在 `base_link` 下方 `(-0.064, 0, -0.059)` 处。在 RL 观察空间中，应注意此偏移量。
*   **躯干碰撞**: `torso_link` 和 `base_link` 都有圆柱体碰撞定义，适合作为跌倒检测的触发器。

## 5. 对配置文件的建议
1.  **刚度 (Stiffness)**: 鉴于 225Nm 的大扭矩上限，膝盖和髋部 Pitch 关节的刚度可以适当调高（例如 80-150），以充分发挥硬件性能。
2.  **足部命名**: URDF 中的足端 Link 统称为 `...foot_roll_link`。配置中的 `foot_name` 必须包含 `"foot"` 字段以确保 `legged_robot.py` 的关键词匹配能成功。
3.  **关节限位**: 膝盖 Pitch 关节范围是 `[-0.09, 1.92]` rad，意味着膝盖只能向后弯曲，配置中的默认角度应保持正值（如 0.6）。
